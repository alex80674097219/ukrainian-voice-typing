# Ukrainian Voice Typing for Windows — moved

**This project has moved and now runs fully offline:**

## → https://github.com/alex80674097219/offline-voice-typing

Same tool, same hotkeys, same Ukrainian support — but recognition now runs
on your own CPU with NVIDIA Parakeet instead of a cloud API. Measured on the
same phrases it is about **6× faster** (0.16 s vs ~1.0 s median, no 5–22 s
stalls), needs no API key, and no audio leaves your computer.

This repository is kept as an archive of the cloud-based version. The full
history is carried over into the new repository.
